# Бартерын хөрөнгийн сайт — шинэчлэл 2026.11.24

- `index.html`: машины жагсаалт, 2026.11.04 PDF-ийн 6 автомашины **анхдагч (fallback)** мэдээлэл.
- `apartments.html`: 2026.10.27 PDF-ийн 13 орон сууц/зогсоолын тусдаа жагсаалт.
- `assets/`: хуучин зургуудаас гадна PDF хуудсын зургууд.
- `apartments.json`: орон сууцны өгөгдөл.

**Чухал:** Firebase-ийн `vehicles` зангилаанд өгөгдөл байгаа бол index.html түүнээс уншиж, PDF-ээс шинэчилсэн fallback жагсаалтыг орлоно. Firebase-д өгөгдлийг автоматаар бичээгүй, устгаагүй. Нийтлэхээс өмнө Firebase-ийн амьд мэдээллийг шалгана уу.

**Үнэ/нэрийн зөрүү:** Century Business Apartment нэгж үнэ; New Ulaanbaatar давхар; Tara Garden / Springs Garden-2 нэр; Lexus LS460 49 сая (ерөнхий хүснэгт) / 40 сая (дэлгэрэнгүй) зөрүүтэй. PDF-ийн ерөнхий хүснэгтийг өгөгдлийн суурь болгосон.

**Аюулгүй байдал:** Анхны ZIP файлд admin/login систем байхгүй. Firebase Realtime Database Rules-д `.write: true` байвал нийтэд нээлттэй хэвээр; нийтлэхээс өмнө Firebase Authentication + сервер талын Rules-аар хамгаална уу. `login.html`-ийн тусад нь явуулсан хуучин хувилбарыг автоматаар нэгтгээгүй, учир нь тэр нь `admin` Custom Claim шаарддаг бөгөөд серверийн эрхийг ZIP-аас олгох боломжгүй.

**Netlify:** ZIP-ийг задлаад файлуудыг GitHub repository-ийн root-д upload/commit хийхэд GitHub-тай холбогдсон Netlify шинэчлэгдэнэ. `index.html` root-д байх ёстой.
